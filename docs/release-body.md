## Antigravity 中文汉化包 v{version}

**不用管版本。** 你装的官方是哪一版都行——以后更新到更新的版本也行。启动时拿新版官方文件
做底座，把已有译文搬上去，界面继续是中文，**不会退回英文**。

### 安装（3 步，约 1 分钟）

1. **完全退出** Antigravity —— 关窗口不够，托盘图标要右键退出
2. 解压本包，双击 **`一键安装汉化.bat`**，看到 `[OK] Chinese pack applied` 即成功
   （文件名里 {version} 只是打包时的版本，不代表只能装在 {version}）
3. 双击桌面上的 **「反重力（中文版）」** 快捷方式启动

首屏要等 30–60 秒中文才全部出现，别太早下结论。包放在哪都行，不用和 Antigravity 装在一起。
装在 `C:\Program Files` 下装不上？先退出 Antigravity，再**右键 `一键安装汉化.bat` →「以管理员身份运行」**，一次就够。

### 版本对不上？

- 官方 = {version} → 全中文
- 官方比 {version} 新 → 启动时把译文搬到新版文件上，界面照旧中文，首次多 2–4 秒
- 官方这次新加的文案 → 那几句暂为英文，其余全中文，下次发版补上

搬的是**文字**，不是文件——代码始终是你自己装的那一版，不会缺功能、不会白屏、不会降级。
看到 `No patch file matching this Antigravity version` 这种提示别慌，那是"没有现成包"的意思，
**直接用「反重力（中文版）」启动**，移植照样进行。

### 出问题怎么办

| 情况 | 做法 |
|---|---|
| 界面还是英文 | 重跑 `一键安装汉化.bat`，或用「反重力（中文版）」再启动一次 |
| 想回到英文原版 | 双击 `一键恢复官方英文.bat`（恢复后请用 Antigravity 自己的图标启动，否则启动器会把中文补回来） |
| 想彻底不被更新打断 | 双击 `关闭自动更新.bat`（可随时用 `恢复自动更新.bat` 撤销） |
