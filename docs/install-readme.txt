Antigravity 中文汉化包 v{version}
=====================================

安装（3 步，约 1 分钟）
---------------------
1. 完全退出 Antigravity（托盘图标也要右键退出）
2. 双击  一键安装汉化.bat
3. 双击桌面上的「反重力（中文版）」快捷方式启动

安装脚本会在桌面创建「反重力（中文版）」快捷方式（图标就是 Antigravity 本体）。
它通过 启动反重力.vbs 拉起客户端：自动设置本地代理环境变量，且不会弹 cmd 黑窗。
不想用快捷方式的话，直接双击本文件夹里的  启动反重力.vbs  效果相同。

首次启动需等 30-60 秒首屏水合完成，中文才全部出现，别太早下结论。

这个文件夹放在哪都行（桌面、下载、U 盘都可以），不用和 Antigravity 装在一起。
脚本会自己找安装目录：先看默认位置，找不到就查注册表里记录的安装路径，
所以当初把客户端装到 D:\Apps\Antigravity 这类自定义目录也能正常识别。


官方更新后会自动恢复中文
-----------------------
只要是通过「反重力（中文版）」快捷方式（或 启动反重力.vbs）启动的，
更新把中文冲掉之后不需要你手动重装，下次启动会自己补回来：

  - 启动前先花约 0.5 秒比对版本和补丁标记（resources\.zh-pack）
  - 发现被覆盖：本地有这个版本的成品就直接复制；没有就从 GitHub Releases 下载
  - 补好再启动，中间只多等几秒
  - 自愈失败一律照常启动（最差就是这次先看英文），绝不会让应用打不开

前提是那个版本的中文包已经发布。官方刚更新、本包还没跟上时，启动会提示
"这个版本的中文包还没有发布"，你可以先用英文版——中文包发布后，下次启动
会自动恢复中文，同样不用手工重装。


建议（可选）：关掉自动更新
-------------------------
双击  关闭自动更新.bat

Antigravity 用 160MB 全量安装包更新：启动 10 秒后就开始检查、之后每小时再查一次，
下载完成后在你退出时自动安装，整个 resources 目录被覆盖。

关掉之后客户端不再发任何更新请求，少一次覆盖、少一次重新补丁，也省流量。
这是官方的 autoCheckForUpdates 设置，不是改文件；随时可用  恢复自动更新.bat  还原，
想更新时也可以从应用菜单里手动检查。

不关也没关系——上面那套自愈机制就是为这种情况准备的。


如果提示"没有匹配当前版本的补丁"
-------------------------------
说明官方比你手上的包新：
  - 到项目 Releases 页下载对应版本（首选，双击即装）
  - 或克隆仓库后自助移植（需 Python 3）：
      python tools/port_to.py --version <你的版本>


回滚
----
双击  一键恢复官方英文.bat，会自动找 app.asar.backup 或 app.asar.bak。
注意：回滚后如果再用「反重力（中文版）」快捷方式启动，自愈会把中文补回来
（这是设计如此）。想彻底回英文，请改用 Antigravity 自己的桌面图标启动。


本包只汉化界面文本，不修改网络请求，不上传任何数据。
