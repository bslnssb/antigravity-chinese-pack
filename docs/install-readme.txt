Antigravity 中文汉化包 v{version}
=====================================

安装（3 步，约 1 分钟）
---------------------
1. 完全退出 Antigravity（托盘图标也要右键退出）
2. 双击  一键安装汉化.bat
3. 双击桌面上的「反重力（中文版）」快捷方式启动

首次启动要等 30-60 秒，中文才全部出现，别太早下结论。
本文件夹放哪都行（桌面、下载、U 盘都可以），脚本会自己找安装目录，
客户端装在 D:\Apps\Antigravity 这类自定义位置也能识别。


以后
----
用「反重力（中文版）」启动就行，其它什么都不用做。

官方更新是整目录覆盖，一定会把中文冲掉——这不是装错了。下次用这个快捷方式
启动，它会自己补回来（先比对补丁标记，被覆盖了就补：本地有成品直接复制，
没有就下载，连对应版本的包都还没发布时现场移植，2-4 秒）。
补不回来也照常启动，最差是这次先看英文，绝不会让应用打不开。

想彻底不被打断：双击  关闭自动更新.bat（随时用  恢复自动更新.bat  还原）。


回滚
----
双击  一键恢复官方英文.bat，会自动找 app.asar.backup 或 app.asar.bak。
注意：回滚后再用「反重力（中文版）」启动，自愈会把中文补回来（设计如此）。
想彻底回英文，请改用 Antigravity 自己的桌面图标启动。


关于代理
--------
启动器会自己找本地代理：先看 tools\local-proxy.txt，再看 Windows 系统代理，
最后扫 7897/7890/10809 等常见端口。探到才用，探不到就不碰任何网络设置。
端口不常见：在 tools\local-proxy.txt 里写一行 127.0.0.1:你的端口（本包不会覆盖这个文件）。


提示"没有匹配当前版本的补丁"
---------------------------
说明官方比你手上的包早一步更新。不用管，直接双击「反重力（中文版）」：
它会拿新版官方文件做底座，把已有译文搬过去，界面继续是中文。
千万别手工把旧版 app.asar.zh-* 改名覆盖，那是整包降级，可能白屏。


本包只汉化界面文本，不修改网络请求，不上传任何数据。
