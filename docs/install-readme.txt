Antigravity 中文汉化包 v{version}
=====================================

安装（3 步，约 1 分钟）
---------------------
1. 完全退出 Antigravity（托盘图标也要右键退出）
2. 双击  一键安装汉化.bat
3. 双击桌面上的「反重力（中文版）」快捷方式启动

首次启动要等 30-60 秒，中文才全部出现，别太早下结论。
本文件夹放哪都行（桌面、下载、U 盘都可以），脚本会自己找安装目录，
客户端装在 D:\Apps\Antigravity 这类自定义位置也能识别。


以后
----
用「反重力（中文版）」启动就行，其它什么都不用做。

官方更新是整目录覆盖，一定会把中文冲掉——这不是装错了。下次用这个快捷方式
启动，它会自己补回来（先比对补丁标记，被覆盖了就补：本地有成品直接复制，
没有就下载，连对应版本的包都还没发布时现场移植，2-4 秒）。
补不回来也照常启动，最差是这次先看英文，绝不会让应用打不开。

想彻底不被打断：双击  关闭自动更新.bat（随时用  恢复自动更新.bat  还原）。


回滚
----
双击  一键恢复官方英文.bat。它自己找安装目录，把 app.asar.backup（或
app.asar.bak）复制回去，并删掉补丁标记 .zh-pack。
以后请用 Antigravity 自己的桌面图标启动——从「反重力（中文版）」启动的话，
自愈会按设计把中文补回来。
复制失败会直接报错退出（多半是 Antigravity 还开着，或装在 Program Files
下没权限：先关掉它，再右键「以管理员身份运行」这个脚本）。


关于代理
--------
启动器会自己找本地代理：先看 tools\local-proxy.txt，再看 Windows 系统代理，
最后扫 7897/7890/10809 等常见端口。探到才用，探不到就不碰任何网络设置。
端口不常见：在 tools\local-proxy.txt 里写一行 127.0.0.1:你的端口（本包不会覆盖这个文件）。

登录要连 Google：请用桌面「反重力（中文版）」启动，别用官方图标——只有前者会把
代理同时传给浏览器和后台进程，直接双击官方图标会直连超时、停在「设置账户失败」页。
启动器会先探测 Google 登录端点，结果写进 %TEMP%\antigravity-launch.log
（PROXY_HEALTH=True/False）。若显示 False，换一个可用节点或开 TUN / 全局模式。

注意：已经开着的窗口不会重新读取 app.asar。官方更新或重新装完中文包后，
要先完全退出 Antigravity，再从桌面图标启动，否则看到的还是旧界面（全英文）。


提示"没有匹配当前版本的补丁"
---------------------------
官方比你手上的包早一步更新，这是常态。安装脚本现在只会给一句提示，然后照常把
桌面启动入口建好，不会中途退出，也不会把旧文件强加到新客户端上。
直接用桌面的「反重力（中文版）」启动：它会拿新版官方文件做底座，把已有译文
搬过去，界面继续是中文。千万别手工把旧版 app.asar.zh-* 改名覆盖，那是整包
降级，可能白屏。

桌面图标点了没反应
------------------
有些电脑会拦截 Windows 脚本宿主（VBS 启动器），表现为双击后什么都没有。
本包另带一份不依赖它的启动器：直接双击文件夹里的  启动反重力.cmd，
或桌面上的  反重力（中文版）.cmd，效果完全一样。


本包只汉化界面文本，不修改网络请求，不上传任何数据。
